Escopo do projeto — Gerador de Memes

1. Propósito e Persona
Um gerador de memes voltado para jovens e usuários de redes sociais que desejam criar memes de forma rápida e simples, sem precisar utilizar programas de edição de imagem. A aplicação permitirá escolher uma imagem, adicionar textos personalizados e gerar um meme pronto para salvar ou compartilhar.

2. Jornada do Usuário
Tela Inicial (Galeria de modelos de memes) ➔ Seleção de um modelo ➔ Editor de Meme ➔ Inserção e personalização dos textos ➔ Visualização em tempo real ➔ Clique no botão Gerar Meme ➔ Exibição do meme finalizado ➔ Opções de Baixar Meme ou Criar Outro.

3. Funcionalidades principais

Galeria de imagensmodelos de memes;
Pesquisa por modelos;
Seleção de uma imagem;
Campo para adicionar texto superior e inferior;
Personalização do texto, como tamanho, posição e cor;
Pré-visualização em tempo real;
Geração do meme;
Download do meme em formato de imagem;
Botão para reiniciar e criar um novo meme;
Interface responsiva para computador e celular.

4. Tecnologias sugeridas

HTML5 — estrutura da aplicação;
CSS3 — estilização e responsividade;
JavaScript — lógica e manipulação do editor;
Canvas API — composição e exportação do meme;
LocalStorage — opcionalmente, para armazenar memes ou modelos favoritos.

5. Objetivo do TCC
Desenvolver uma aplicação web interativa que demonstre conhecimentos de desenvolvimento Front-end, manipulação do DOM, eventos, responsividade, criação de interfaces e processamento de imagens no navegador, proporcionando ao usuário uma maneira simples e rápida de criar memes personalizados.
